提交数据

提交数据需要拥有 GitHub 账号或百合会账号，系统会自动整理内容，确认后跳转提交。

数据提交通道尚未配置。站点维护者需要在 data/config.js 中把 backend 设为 githubIssue 并填入 githubIssueRepo（或改用 Web3Forms / Formspree）， 提交功能才会启用。具体步骤见 审核流程。

章节情况

点击色块左上半（亲吻）或右下半（ちくび）切换：未知 → 有 → 无；点击 + 可插入 .5 特典章节。

章节 tag 分配

选择章节后点击即可为选择的章节添加 tag 。特殊情况可以自行输入 tag，如有必要将会采用作为新 tag

已有 tag（点选即添加）

    章节情况

    粉色/紫色 = 有记录；灰色 = 无记录；蓝色 = 未知。

    点击章节之间的 + 可插入 .5 特典章节，点击最后一章后面的 + 可新增章节。

    章节 tag 分配

    选择章节。下方会列出目前网站上已有的所有 tag，选好章节后点一下 tag 即可添加；也可以输入新 tag 后手动添加。

    已有 tag（点选即添加）

      tags 说明

      • 人物遮挡：指嘴唇被人物头部等遮挡
      • 环境遮挡：指嘴唇被环境或物体遮挡
      • 无上色：ちぐび专用tag，只画出凸起的形状，需要与单纯的没画作出区分
      • 衣物：ちぐび专用tag，透过衣物

      确认投稿内容

      点击下方按钮将打开 GitHub Issue 页面或百合会页面
      带有预填功能 无需自行复制内容。
