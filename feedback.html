提交场景数据

新增漫画或修改已有漫画的亲吻/露点记录。佐证图片仅用于维护者审核，不会在网站上展示。

数据提交通道尚未配置。站点维护者需要在 data/config.js 中把 backend 设为 githubIssue 并填入 githubIssueRepo（或改用 Web3Forms / Formspree）， 提交功能才会启用。具体步骤见 审核流程。
封面仅用于帮助维护者识别漫画；单张不超过 10MB。

章节情况

默认全部未知（蓝色问号）。点击色块左上半（亲吻）或右下半（露点）切换：未知 → 有 → 无。

章节情况

粉色/紫色 = 有记录；灰色 = 无记录；蓝色问号 = 未知（仅显示已有的未知，不能修改成未知）。点击半边仅在“有 / 无”之间切换。

佐证图片选填 · 每张必须备注对应章节 · 最多 30 张
支持 jpg / png / webp，单张不超过 10MB。图片不会公开展示。

确认投稿内容

点击下方绿色按钮将打开 GitHub Issue 页面（提交框已预填内容）。
图片不会自动上传：请在 GitHub Issue 编辑器里，按下方图片清单手动拖入对应图片。

前往 GitHub 提交 Issue

🔒 隐私说明：佐证图片通过第三方表单服务直接发送到维护者邮箱，本站不存储、不公开展示。 数据上架前由维护者人工核对，通过后仅把文字信息写入 data/manga-data.js。
