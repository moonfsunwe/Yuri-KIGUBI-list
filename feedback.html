提交场景数据

提交数据需要拥有 GitHub 账号：填写下方表单后，系统会自动整理成 GitHub Issue 内容，确认后跳转到 GitHub 提交。

数据提交通道尚未配置。站点维护者需要在 data/config.js 中把 backend 设为 githubIssue 并填入 githubIssueRepo（或改用 Web3Forms / Formspree）， 提交功能才会启用。具体步骤见 审核流程。

章节情况

默认全部未知（蓝色问号）。点击色块左上半（亲吻）或右下半（露点）切换：未知 → 有 → 无；把鼠标移到相邻章节之间的 +，可插入 .5 特典章节。

章节情况

粉色/紫色 = 有记录；灰色 = 无记录；蓝色问号 = 已有未知（不能修改成未知）。点击半边仅在“有 / 无”之间切换；相邻整数章节之间的 + 可插入 .5 特典章节。

确认投稿内容

点击下方按钮将打开 GitHub Issue 页面（标题、正文和标签已根据表单预填）。
请在 GitHub 中确认内容后点击 Submit new issue。
